# Ultimate Hub Roblox Script

Repository script cheat Roblox survival horror (**Ultimate Hub V10.3 | ToingDC**).

## 🚀 Cara Menjalankan (Loadstring)

Jalankan salah satu script berikut di Roblox Executor (Delta, Codex, Fluxus, Wave, Arceus X, Hydrogen, dll):

### Opsi 1 (Format TXT - Rekomendasi):
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/luya8281-tech/script-roblox/main/Hi.txt"))()
```

### Opsi 2 (Format LUA):
```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/luya8281-tech/script-roblox/main/loader.lua"))()
```

---

## 📁 Struktur Berkas

- **`core.lua`**: Modul backend engine utama (`UHCore`), menangani logika ESP, Walkspeed, Aimbot, Auto-attack, Auto-repair Generator, dan Remote hooks.
- **`Hi.txt` / `loader.lua`**: Rayfield GUI loader v10.3 yang secara otomatis memuat `core.lua` langsung dari repositori ini.
